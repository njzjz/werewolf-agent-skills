# 狼人杀游戏组织 Skill

## 架构设计

本 Skill 使用多 Session 协作架构：

```
主 Session (你)
    ├── 向用户展示规则和结果
    ├── 接收用户指令（开始游戏、查看状态）
    └── 协调子 Session

法官 Session (子 Agent)
    ├── 管理游戏状态
    ├── 分配角色
    ├── 组织夜间/白天流程
    └── 收集玩家行动

玩家 Sessions (多个子 Agent)
    ├── 每个 AI 玩家一个独立 Session
    ├── 接收角色信息
    ├── 执行角色技能（刀人、查验、投票等）
    └── 进行发言和推理
```

## 快速开始

### 1. 开始一局游戏

```
开始狼人杀游戏
- 玩家：玩家1、玩家2、玩家3、玩家4、玩家5、玩家6、玩家7、玩家8、玩家9
- 板子：9人标准
```

### 2. 系统会自动：
- 创建法官 Session
- 为每个玩家创建 AI Session（如果是 AI 玩家）
- 分配角色
- 开始游戏流程

### 3. 游戏进行
- 主 Session 会在群里实时播报游戏进展
- 用户可以看到夜间死亡、白天投票等结果
- 如果是真人玩家，通过主 Session 输入行动

## 游戏流程

### 初始化阶段
1. 确定玩家列表（真人 + AI）
2. 选择板子（6人/9人/12人）
3. 创建法官 Session，初始化游戏
4. 为 AI 玩家创建子 Session，分配角色 Prompt

### 夜晚阶段（循环）
1. **狼人行动**：
   - 法官向所有狼人玩家广播消息，告知狼队友名单
   - 每个狼人单独提交击杀目标建议
   - 法官汇总后，若意见一致则执行，不一致则随机选择或让首个狼人决定
2. **女巫行动**：女巫 Session 决定是否救人/毒人
3. **预言家行动**：预言家 Session 选择查验目标
4. **守卫行动**：守卫 Session 选择守护目标（如有）
5. 法官处理夜间结果，计算死亡

### 白天阶段（循环）
1. **公布死亡**：主 Session 播报昨夜死亡情况
2. **遗言**：死亡玩家发表遗言（首夜）
3. **发言环节**：所有存活玩家依次发言
4. **投票环节**：玩家投票，最高票者出局
5. **结算**：处理白痴亮身份、猎人开枪等

### 结束判定
- 狼人全死 → 好人胜利
- 神职全死或平民全死 → 狼人胜利

## 角色配置

参考 [维基百科狼人杀板子](https://zh.wikiversity.org/wiki/狼人殺/板子)

### 6人局（明牌局）
- 2狼人 vs 预言家+猎人+2平民

### 9人局（标准局）
- 3狼人 vs 预言家+女巫+猎人+3平民

### 12人局（预女猎白标准板）
- 4狼人 vs 预言家+女巫+猎人+白痴+4平民

## 使用 scripts/

### game_engine.py
游戏状态管理脚本，由法官 Session 调用：

```python
# 初始化游戏
python game_engine.py setup '["玩家1","玩家2",...]' '9人标准'

# 获取游戏状态
python game_engine.py state
```

### player_prompts.py
生成玩家角色的系统 Prompt：

```python
from player_prompts import get_role_prompt

prompt = get_role_prompt("狼人", "玩家A", ["玩家B"], ["玩家A", "玩家B", "玩家C"])
```

## 实现步骤

### Step 1: 创建法官 Session
```python
sessions_spawn(
    task="你是狼人杀法官。使用 game_engine.py 管理游戏。等待玩家列表和板子配置。",
    label="werewolf-judge"
)
```

### Step 2: 初始化游戏
向法官 Session 发送玩家列表和板子，获取角色分配。

### Step 3: 创建玩家 Sessions
为每个 AI 玩家创建 Session，使用 player_prompts.py 生成对应角色的系统 Prompt。

### Step 4: 游戏循环
1. 通知法官进入夜晚
2. 法官依次询问各角色行动
3. 法官处理结果，返回死亡信息
4. 主 Session 播报结果
5. 进入白天，组织发言和投票
6. 重复直到游戏结束

## 消息格式

### 法官 → 主 Session
```json
{
  "phase": "night_result",
  "day": 1,
  "deaths": ["玩家名"],
  "winner": null
}
```

### 玩家 → 法官
```
狼人: "击杀: 玩家A"
预言家: "查验: 玩家B"
女巫: "救人" / "不救" / "毒: 玩家C"
白天投票: "投票: 玩家D"
```

## 注意事项

1. **状态持久化**：法官 Session 需要维护游戏状态，可使用文件或内存
2. **同步机制**：夜间行动需要按顺序进行，等待每个角色响应
3. **超时处理**：如果玩家 Session 超时，法官需要做出默认选择
4. **真人玩家**：如果有真人参与，通过主 Session 转发其行动给法官
