# 狼人杀游戏规则

## 基本流程

### 1. 游戏准备
- 确定玩家人数（建议 6-12 人）
- 分配身份牌（狼人、平民、神职）
- 所有玩家闭眼，游戏开始

### 2. 夜晚阶段（循环）
1. **狼人睁眼**：狼人互相确认身份，选择一名玩家击杀
2. **女巫睁眼**：告知昨夜死亡玩家，可选择救人或使用毒药
3. **预言家睁眼**：选择一名玩家查验身份（好人/狼人）
4. **其他神职**（如有）：按规则执行技能

### 3. 白天阶段（循环）
1. **公布死亡**：宣布昨夜死亡玩家（或平安夜）
2. **遗言**：死亡玩家发表遗言（首夜死亡有遗言）
3. **发言环节**：存活玩家依次发言
4. **投票环节**：所有玩家投票，票数最多者出局
5. **公布结果**：出局玩家发表遗言（部分规则限制）

### 4. 胜负判定
- **狼人胜利**：所有神职死亡，或所有平民死亡，或狼人数量≥好人数量
- **好人胜利**：所有狼人死亡

## 常见板子（配置）

### 6人局（新手）
- 2狼人 + 4平民

### 9人局（标准）
- 3狼人 + 3平民 + 1预言家 + 1女巫 + 1猎人

### 12人局（完整）
- 4狼人 + 4平民 + 1预言家 + 1女巫 + 1猎人 + 1白痴/守卫

## 特殊规则

### 女巫
- 首夜可以自救（部分规则允许）
- 解药和毒药不能同一晚使用
- 解药用完则无法看到死亡信息

### 猎人
- 被投票出局可以开枪带走一人
- 被女巫毒死不能开枪

### 白痴
- 被投票出局时亮明身份，免于死亡但失去投票权
- 可以继续发言

### 守卫
- 每晚可守护一名玩家（不能连续两晚守护同一人）
- 被守护玩家当晚不会被狼人杀死
- 若女巫解药和守卫守护同一人，该人死亡（奶穿）
